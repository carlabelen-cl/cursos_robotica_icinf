## 📌 Sobre este Repositorio

Este repositorio contiene el material técnico, guías de implementación, diagramas de conexión y código fuente para **4 Estaciones Prácticas de Robótica e Interacción Hardware-Software**.

Cada estación está diseñada como un módulo de aprendizaje independiente que aborda conceptos fundamentales de la informática y la ingeniería, tales como:
- Circuitería y física de materiales conductores.
- Programación lógica por bloques y estructurada.
- Captura de entradas físicas y procesamiento de eventos en tiempo real.
- Interacción humano-computador (HCI).
